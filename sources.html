Academic Reference Document

Bibliography of Academic Sources & Technical RFC Standards

This document details the primary university textbook literature, curriculum materials, and formal Request for Comments (RFC) engineering standards from the Internet Engineering Task Force (IETF) and IEEE that serve as the authoritative baseline for the OSI 7-Layer Interactive Protocol Suite.

1. Foundational Computer Networks Literature

Computer Networking: A Top-Down Approach (8th Edition)

Pearson (2021) • ISBN: 978-0136681557

James F. Kurose (University of Massachusetts Amherst) & Keith W. Ross (NYU)

Curricular Application: Primary pedagogical foundation for application-layer socket mechanics, DNS hierarchical resolution, HTTP/1.1 vs. HTTP/2 vs. HTTP/3 protocol evolution, TCP state machine sequences (3-way handshake and teardown), congestion control algorithms (Tahoe, Reno), and router architecture.

Citation (APA): Kurose, J. F., & Ross, K. W. (2021). Computer Networking: A Top-Down Approach (8th ed.). Pearson.

Computer Networks (6th Edition)

Pearson (2021) • ISBN: 978-0133594140

Andrew S. Tanenbaum (Vrije Universiteit), David J. Wetherall (Google/UW), Nick Feamster (University of Chicago)

Curricular Application: Theoretical baseline for the complete 7-Layer OSI Reference Model (ISO/IEC 7498-1), Service Data Unit (SDU) vs. Protocol Data Unit (PDU) encapsulation hierarchy, Layer 2 framing methods, hardware CRC checksum polynomials, and Physical layer transmission media.

Citation (APA): Tanenbaum, A. S., Wetherall, D. J., & Feamster, N. (2021). Computer Networks (6th ed.). Pearson.

TCP/IP Illustrated, Volume 1: The Protocols (2nd Edition)

Addison-Wesley Professional (2011) • ISBN: 978-0321336316

W. Richard Stevens & Kevin R. Fall (Carnegie Mellon)

Curricular Application: Exact architectural bitfield layouts for protocol headers (IPv4, IPv6, TCP, UDP, ICMP, ARP), bitwise flag definitions, sliding window mathematical formulas, and command-line network diagnostics.

Citation (APA): Fall, K. R., & Stevens, W. R. (2011). TCP/IP Illustrated, Volume 1: The Protocols (2nd ed.). Addison-Wesley Professional.

2. Authoritative IETF Request for Comments (RFC) Standards

Every header structure, sequence number rule, and socket behavior rendered in the suite corresponds to formal IETF Requests for Comments (RFCs) and IEEE standard specifications:

Layer 7: Application Standards IETF RFCs
  • RFC 9114 (2022): HTTP/3 — Hypertext Transfer Protocol over QUIC.
  • RFC 7540 (2015): HTTP/2 — Binary Framing Layer and Multiplexed Streams.
  • RFC 9110 (2022): HTTP Semantics (Obsoleting RFC 2616 / RFC 7230).
  • RFC 1034 & 1035 (1987): Domain Names — Concepts, Facilities, and Implementation.
  • RFC 2131 (1997): Dynamic Host Configuration Protocol (DHCP DORA Specification).
  • RFC 5321 (2008): Simple Mail Transfer Protocol (SMTP Push Infrastructure).
  • RFC 3501 & 9051 (2021): Internet Message Access Protocol (IMAP4rev2 Pull).
  • RFC 4251–4254 (2006): The Secure Shell (SSH) Protocol Architecture.
Layers 5 & 6: Session & Presentation IETF & ITU-T
  • RFC 8446 (2018): The Transport Layer Security (TLS) Protocol Version 1.3.
  • ITU-T Rec. X.680 / X.690: Abstract Syntax Notation One (ASN.1) & BER/DER Rules.
  • RFC 4506 (2006): XDR: External Data Representation Standard.
  • RFC 8259 (2017): The JavaScript Object Notation (JSON) Data Interchange Format.
  • RFC 1928 (1996): SOCKS Protocol Version 5.
  • RFC 1831 (1995): RPC: Remote Procedure Call Protocol Specification Version 2.
  • RFC 3261 (2002): SIP: Session Initiation Protocol.
  • RFC 1700 (1994): Assigned Numbers — Standard Network Byte Order (Big-Endian).
Layer 4: Transport Standards IETF RFCs
  • RFC 9293 (2022): Transmission Control Protocol (TCP) Specification (Consolidates RFC 793, 1122, 1323, 7323).
  • RFC 768 (1980): User Datagram Protocol (UDP Specification).
  • RFC 9000 (2021): QUIC: A UDP-Based Multiplexed and Secure Transport.
  • RFC 6335 (2011): IANA Service Name and Transport Protocol Port Number Registry Procedures.
Layers 1–3: Lower Architecture Standards IEEE & IETF
  • RFC 791 (1981): Internet Protocol (IPv4) Specification.
  • RFC 8200 (2017): Internet Protocol, Version 6 (IPv6) Specification (Internet Standard).
  • RFC 792 & 4443: Internet Control Message Protocol (ICMPv4 & ICMPv6).
  • RFC 2328 (1998): OSPF Version 2 & RFC 4271 (2006): BGP-4.
  • RFC 1918 (1996): Address Allocation for Private Internets.
  • RFC 4291 (2006): IP Version 6 Addressing Architecture & EUI-64 Format.
  • IEEE 802.3: Ethernet MAC Framing, Interframe Gap & 32-Bit FCS CRC-32.
  • ANSI/TIA-568-D: Commercial Building Telecommunications Cabling Standard (T568A/T568B).

Pedagogical Philosophy & Educational Verification

The design goal of this suite is to serve as an interactive, verifiable bridge between textbook theory and actual systems engineering. By providing interactive packet bitfield dissection, dynamic sequence and acknowledgment tracking, live encapsulation/decapsulation stages, and authentic terminal diagnostics, students can test hypotheses, verify calculations, and master networking concepts with immediate visual feedback.
